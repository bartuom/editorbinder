## EditorBinder 0.1.3

EditorBinder 0.1.3 focuses on reliability and safety across the local tool library, AI-assisted authoring workflow, and Windows desktop experience. The bundled Free Core remains at 21 Unreal Engine tools.

### Reliability and safety

- Expanded Unreal Python linting for additional mutating Actor/component operations and unreal.log_error().
- Added strict UTF-8 decoding with BOM tolerance for imported libraries and settings.
- Made library and settings writes atomic, flushed and synced before replacement, and cleaned up temporary files after failed writes.
- Rejected unsafe ZIP archive members, including absolute paths, drive-qualified paths, and parent traversal.
- Tracked and cancelled pending Tkinter timers during dialog teardown.
- Routed AI-generation results through a thread-safe queue so Tkinter updates remain on the UI thread.
- Hardened monitor and work-area geometry validation.

### Validation

- 215 automated tests passed locally.
- Ruff static checks and Python bytecode compilation passed.
- GitHub Actions Windows CI passed on Python 3.10, 3.11, and 3.12.
- The release workflow builds and verifies the versioned Windows EXE, portable ZIP, and source ZIP on a clean Windows runner.

### Notes

- No new bundled Unreal tool scripts are introduced in this release.
- EditorBinder is a local clipboard library. It does not execute scripts directly inside Unreal Editor. Review scripts and test them in a safe copy of a level before production use.
- The Windows executable is unsigned. Microsoft Defender SmartScreen may show an Unknown publisher warning on first launch.
