## EditorBinder 0.1.2

EditorBinder 0.1.2 expands the Free Core library to 21 tools and delivers a broad reliability update across AI-assisted authoring, editor workflows, window recovery, and Windows packaging.

### New Unreal Engine tools

- **Select Actors By Material** searches level actors by material name or asset path.
- **Batch Update Actor Tags** adds, removes, or replaces tags on selected actors with undo support.
- **Audit Missing Material Slots** reports empty material assignments on selected actors and can select affected actors.

### Reliability and workflow improvements

- Safer AI endpoint validation and secret redaction.
- Better recovery from truncated AI output and incomplete code fences.
- More reliable numeric parameter interaction and compact-row keyboard shortcuts.
- Window position recovery across monitor changes and safer dialog shutdown.
- More accurate syntax-aware Unreal Python linting.
- Cleaner source ZIP and Windows release packaging.

### Validation

- 191 automated tests passed locally, with the merged CI matrix green on Python 3.10, 3.11, and 3.12.
- Ruff static checks passed.
- Windows onedir and standalone EXE packages built and verified.
- Source ZIP and wheel installation smoke tests passed.

### Windows note

The Windows executables are not code-signed. Microsoft Defender SmartScreen may show an Unknown publisher warning. Download only from the official GitHub Releases page.
